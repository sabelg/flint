# What Flint needs to ship a state-of-the-art game

Engine-wide review · November 26, 2026 · Flint v5 / Mojo 1.2

**Flint now has a packaged character encounter in Sunspire Valley.** The implementation round used that level to check animation, streaming, lighting, audio, accessibility, save compatibility and frame delivery. The original review and its acceptance criteria follow the measured results.

## Implementation and qualification

The implementation round put the performer into the normal Sunspire player, added a recoverable creator workflow and measured limits on the Linux AArch64 GB10. The findings under “What the panel reviewed” describe the starting revision. Current qualification uses the commands in the [character course guide](../examples/character_course/README.md).

## The character an artist would ship

**Materials and motion need a shared reference asset.** The GLB path quantizes a linear base-color factor to a byte and then decodes it as sRGB. A factor of 0.5 becomes approximately 0.212 scene-linear by inspection. Missing metallic/roughness factors resolve to 0/0.55, where glTF specifies 1/1. The renderer substitutes a fixed mask cutoff, and native animation import skips `weights` channels even though morph geometry can load. Build one redistributable fixture with calibrated swatches, a 0.25 cutout, two skins, blended elbow weights, a rigid attachment and a keyed facial expression. Compare scene-linear pixels, silhouette and named vertices in Studio and in the cooked player against an independent reference. [Importer](../src/flint/assets/glb_native.mojo) · [Material conversion](../src/flint/render/render_world.mojo) · [Khronos glTF specification](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html)

**Prove simultaneous GPU deformation.** The working-tree GPU allocator holds 2,048 palette joints and 98,304 vertices. On exhaustion it can overlap live joints or return a shortened vertex range. The seven-primitive performer requests 112 joints per instance on this path, so the 19th crosses the joint limit from an empty arena. The Studio candidate reuses freed space, but still returns an overlapping slot on true exhaustion. This is a source-derived threshold. Spawn 19 distinct poses, record the oldest actor’s vertices, then despawn, reload and respawn for 100 cycles. Require intact existing actors, an explicit result for excess demand and bounded memory. The existing course draws its diagnostic character with CPU skinning. Render this same performer through the packaged GPU path. [Skin allocator](../src/flint/render/aaa_skinning_rt.mojo) · [ECS renderer](../src/flint/render/plugin.mojo) · [Course](../examples/character_course/main.mojo)

**Make the animator’s time a product metric.** The existing pivot ends at 90° with about 13–15 mm of planted-ankle movement. The physical get-up still achieved 0/3 on its standing criterion in repeated runs of the same case. Retain the authored get-up for the first level. Have an animator retarget, fix a foot plant, bake and reopen a turn on two different rigs. Record hands-on minutes, drift, contact error and any manual file edits. Start with a 2 cm stance-drift target on this task. Let the animator rewind a bad turn and inspect the winning pose, continuation and component costs. Fund active balance research when a controller transfers load to the feet and stands across a spread of starting poses. Model-backed motion generation needs separate evidence with identified weights and usage rights. The saved gate exercised the motion math and skipped the external SOMA model run. [Character measurements](ANIMATION_PHYSICS_REVIEW.md) · [Matcher](../src/flint/anim/motion_matching.mojo) · [Motion workflows](NATIVE_MOTION_ROADMAP.md) · [Model notices](../licenses/README.md) · [Epic’s motion-matching debugger](https://dev.epicgames.com/documentation/unreal-engine/motion-matching-debugging-in-unreal-engine)

## Integrate the branches in a defensible order

1. **Protect a reproducible baseline.** `57bc3cd` is 18 commits ahead of `c72c926` with no main-only commits. It already contains the `gaps-core`, `gaps-docs`, `gaps-gpu`, `gaps-lighting`, `gaps-net`, `gaps-navai` and `gaps-audio` candidates, plus Studio, game-runtime and device-recovery work. Preserve the working-tree character fixes and tests before qualifying the combined candidate. Reuse `f4647b9` for CPU CI and `c40eb00` for the scaffold-to-player path. Require the cooker, reload, actor exhaustion and lifecycle cases on the combined tree. Software Vulkan CI and a manual GPU job serve different hardware coverage needs.
2. **Bring the graphics benchmark over before its optimizations.** At `e9869ad`, `v5` is 124 commits ahead of main and lacks 22 main commits. From the common ancestor `c29afd2`, the reviewed Studio and v5 lines both touched 50 paths. That count measures overlap. Inspect semantics in shared renderer, resource and platform code. For each candidate, run baseline and candidate against the same content, camera, driver, resolution and cache state. Promote measured improvements independently with a fallback and a named owner.
3. **Budget research against a player problem.** The motion toolchain, optional auto-rig and NPC inference lines are plausible differentiators. An animator finishing a better motion edit in less time is a stronger investment case than an additional model integration. If NPC dialogue is required, test asynchronous decisions against a deterministic behavior-tree fallback under load. Keep external models and evaluation-only clips under their own distribution terms. The game should exercise its core loop from distributable assets on a fresh install. [Third-party notices](../licenses/README.md)

## Reproducing the evidence

The normal entry points are `bash tools/flint.sh gate`, `bash tools/flint.sh lab render`, `bash tools/flint.sh world --shots`, and `bash tools/flint.sh new` on a disposable destination. For the cooker, start with a valid GLB and config, retain a copy of the output, change a same-length config value while restoring its mtime, compare incremental and empty-cache archives, then replace the GLB with malformed bytes and compare the previous archive after the expected failure.

Local review outputs and small Mojo probe sources are in `build/engine-study/`, with the earlier full-gate record in `build/character-course/gate-round2.log`.
